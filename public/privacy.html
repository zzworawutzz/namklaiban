น้ำใกล้บ้านฉัน

หน้านี้อธิบายว่าเว็บและบอต LINE "น้ำใกล้บ้านฉัน" เก็บข้อมูลอะไรของคุณ เพื่ออะไร เก็บนานแค่ไหน ส่งต่อให้ใคร และคุณจัดการข้อมูลของตัวเองได้อย่างไร

ปรับปรุงล่าสุด 2 ตุลาคม 2569

สรุปสั้นๆ

  • เว็บไม่ต้องสมัครสมาชิก ไม่ใช้คุกกี้ ไม่มีระบบวิเคราะห์การใช้งาน (analytics) และไม่เก็บการเลือกของคุณไว้ในเบราว์เซอร์
  • บอต LINE เก็บ รหัสผู้ใช้ LINE กับตำแหน่งที่คุณส่งให้ (ไม่เกิน 3 จุด) เพื่อแจ้งเตือนเท่านั้น พิมพ์ "ยกเลิก" เมื่อไรก็ลบทั้งหมดทันที หรือบล็อกบอตก็ลบให้อัตโนมัติ
  • รายงานน้ำท่วม เก็บแค่จุด ระดับน้ำ หมายเหตุ และเวลา ไม่เก็บชื่อหรือรูป และลบอัตโนมัติใน 48 ชั่วโมง
  • เราไม่ขายข้อมูล ไม่ส่งข้อมูลให้ผู้โฆษณา และไม่ใช้ข้อมูลของคุณเพื่อจุดประสงค์อื่นนอกจากที่เขียนไว้ที่นี่

1. เมื่อคุณใช้เว็บ

สิ่งที่อยู่แค่ในเครื่องของคุณ

ปุ่ม "ใกล้ฉัน" และ "ตำแหน่งฉัน" ใช้ตำแหน่งจากเบราว์เซอร์ของคุณ (ต้องกดอนุญาตก่อน) หมุดบ้านที่คุณปักบนแผนที่ก็ใช้เฉพาะตอนเปิดหน้านั้นอยู่ ไม่ถูกบันทึกไว้ที่ใด เว็บไม่เขียนข้อมูลลงที่เก็บข้อมูลของเบราว์เซอร์ (localStorage/คุกกี้) ระบบเก็บเฉพาะไฟล์ของหน้าเว็บ (service worker cache) และรายการสถานีวัดน้ำล่าสุดที่โหลดสำเร็จ (ข้อมูลสาธารณะ ไม่มีข้อมูลส่วนตัวหรือตำแหน่งของคุณ เก็บใน Cache ของเบราว์เซอร์ชื่อ nkb-data) เพื่อให้เปิดได้เร็ว เปิดได้แม้สัญญาณอ่อน และแสดงข้อมูลที่บันทึกไว้พร้อมบอกอายุระหว่างรอข้อมูลใหม่ ล้างได้จากการตั้งค่าเบราว์เซอร์

ปุ่ม "แชร์ลิงก์จุดนี้" สร้างลิงก์ที่มีพิกัดของจุดนั้นปัดเป็นราว 100 เมตร (เช่น ?lat=13.912&lng=100.545) และไม่มีอย่างอื่น ลิงก์ถูกสร้างและส่งโดยคุณเอง เราไม่เก็บลิงก์หรือพิกัดนั้นไว้ที่ใด ใครมีลิงก์จะเห็นว่าจุดนั้นอยู่แถวไหน จึงควรแชร์เฉพาะกับคนที่คุณไว้ใจ ถ้าเป็นตำแหน่งปัจจุบันของคุณ ผู้รับจะเห็นพื้นที่ที่คุณอยู่ตอนนั้น

สิ่งที่ถูกส่งไปยังบริการภายนอกจากเบราว์เซอร์ของคุณโดยตรง

เพื่อให้ฟีเจอร์ทำงาน เบราว์เซอร์ของคุณจะติดต่อบริการเหล่านี้ ซึ่งเห็นที่อยู่ IP ของคุณและข้อมูลตามที่ระบุ และมีนโยบายของตัวเอง

บริการใช้ทำอะไรข้อมูลที่ส่ง
OpenStreetMap (แผนที่พื้นหลัง, ค้นหาสถานที่)แสดงแผนที่ และค้นหาชื่อสถานที่ส่วนของแผนที่ที่คุณดู; คำที่ค้นหาและชื่อต้นทาง/ปลายทางที่คุณพิมพ์ (เมื่อกด Enter ค้นหาหรือตรวจเส้นทาง)
OSRM (project-osrm.org)คำนวณเส้นทางในฟีเจอร์เช็กเส้นทางพิกัดต้นทางและปลายทาง
Open-Meteoพยากรณ์ฝน และความสูงของพื้นที่เหนือระดับน้ำทะเล (เฉพาะเมื่อคุณใช้ตำแหน่งปัจจุบันหรือปักหมุดบ้าน)พิกัดของพื้นที่ที่เลือก (จังหวัด ตำบล ตำแหน่งปัจจุบัน หรือหมุดบ้าน)
Open-Meteo (จากเซิร์ฟเวอร์ของเรา)พยากรณ์ฝนสำหรับบรรทัดเตือนฝนหนักในสรุปเช้าทาง LINEพิกัดกลางของสถานีในจังหวัด (ไม่ใช่ตำแหน่งของคุณ) เรียกวันละครั้งต่อจังหวัด
RainViewerเรดาร์ฝน (เมื่อคุณเปิดชั้นนี้)ส่วนของแผนที่ที่ดู
Cloudflare cdnjs, Google Fontsโหลดโปรแกรมแผนที่และตัวอักษรคำขอไฟล์ตามปกติ (ที่อยู่ IP)
Google Maps (เมื่อกด "นำทาง")นำทางไปศูนย์พักพิงพิกัดศูนย์พักพิงที่คุณเลือก (ลิงก์เปิดบนแอป/เว็บของ Google)

ภาพน้ำท่วมจากดาวเทียม (GISTDA) เรียกผ่านเซิร์ฟเวอร์ของเรา ที่อยู่ IP ของคุณไม่ถูกส่งต่อไปยัง GISTDA

ที่เซิร์ฟเวอร์ของเรา

เมื่อคุณเปิดหน้าเว็บ ผู้ให้บริการโฮสต์ (Vercel) อาจบันทึกบันทึกการเข้าใช้งานตามปกติ เช่น ที่อยู่ IP และเวลา เพื่อความปลอดภัยและแก้ปัญหา ตามนโยบายของผู้ให้บริการนั้น ระบบของเราไม่นำข้อมูลนี้ไปวิเคราะห์หรือเชื่อมโยงกับตัวคุณ

ในช่องค้นหา ตัวอักษรที่คุณพิมพ์จะถูกส่งมาที่เซิร์ฟเวอร์ของเราเพื่อหาชื่อแนะนำ (จังหวัด อำเภอ ตำบล สถานีวัดน้ำ ศูนย์พักพิง) เราไม่บันทึกคำที่พิมพ์ไว้ และจะส่งไปยัง OpenStreetMap ก็ต่อเมื่อคุณกด Enter เพื่อค้นหาชื่อสถานที่ หรือกดตรวจเส้นทางเท่านั้น

การ์ดฝนแสดงฝนที่เครื่องวัดฝนของ ThaiWater วัดได้จริง เซิร์ฟเวอร์ของเราดึงข้อมูลนั้นมาและตอบเบราว์เซอร์ของคุณ เมื่อคุณใช้ตำแหน่งปัจจุบันหรือหมุดบ้าน พิกัดจะถูกส่งมาที่เซิร์ฟเวอร์ของเราเพื่อหาเครื่องวัดฝนที่ใกล้ที่สุด (เช่นเดียวกับการหาสถานีวัดน้ำที่ใกล้ที่สุด) เราไม่บันทึกพิกัดนั้น และไม่ส่งต่อให้ ThaiWater

2. เมื่อคุณแจ้งจุดน้ำท่วม

เมื่อกด "ส่งรายงาน" (บนเว็บหรือผ่านบอต LINE) เราเก็บ

  • พิกัดของจุดที่ท่วม ระดับน้ำที่เลือก หมายเหตุสั้นๆ (ถ้าใส่) และเวลาที่ส่ง
  • ตัวระบุแบบแฮช (ผลคำนวณทางเดียวจากที่อยู่ IP หรือรหัส LINE ผสมค่าลับของระบบ ย้อนกลับเป็น IP หรือรหัสเดิมไม่ได้) ใช้ เพียงเพื่อจำกัดจำนวนครั้งการส่ง (ไม่เกิน 5 ครั้งต่อชั่วโมง) นับจำนวนคนที่ยืนยัน และนับโหวต "ไม่จริง" ไม่ให้ซ้ำคนเดิม และไม่เปิดเผยออกทาง API หรือหน้าเว็บ

ไม่เก็บชื่อ รูป หรือข้อมูลที่ระบุตัวตนอื่นๆ ข้อความหมายเหตุที่คุณพิมพ์จะแสดงต่อสาธารณะ จึงโปรดอย่าใส่ชื่อ เบอร์โทร หรือข้อมูลส่วนตัวของตัวเองหรือผู้อื่น

ระยะเวลา: หมุดแสดงบนแผนที่ 12 ชั่วโมงแล้วหายไป (หรือถูกซ่อนเมื่อมี 3 คนที่ต่างกันกด "ไม่จริง") และข้อมูลทั้งหมดของรายงานถูกลบถาวรจากฐานข้อมูลเมื่อครบ 48 ชั่วโมง

3. เมื่อคุณใช้บอต LINE

ข้อมูลที่เก็บ

  • รหัสผู้ใช้ LINE ของคุณ (ที่ LINE ส่งให้บอต ไม่ใช่ชื่อหรือรูปโปรไฟล์ และเราไม่ขอข้อมูลโปรไฟล์) หรือรหัสกลุ่ม/ห้องแชต ถ้าคุณเชิญบอตเข้ากลุ่ม
  • ตำแหน่งที่คุณส่งให้บอต สูงสุด 3 จุด พร้อมชื่อจุด ("บ้านของคุณ", "จุดที่ 2", "จุดที่ 3")
  • การตั้งค่าของคุณ เช่น ระดับการแจ้งเตือน ช่วงไม่รบกวนกลางคืน เปิดปิดสรุปเช้า เวลาที่การพักแจ้งเตือนสิ้นสุด (ถ้ากดพัก) และสถานะที่แจ้งไปล่าสุด (เพื่อไม่ส่งซ้ำ)
  • สำหรับกลุ่ม: จังหวัดที่ตั้งให้ส่งสรุปเช้า
  • ขณะที่คุณทำขั้นตอน "แจ้งน้ำท่วม" ค้างอยู่: ระดับน้ำที่เลือกและเวลา เก็บชั่วคราวเพื่อรอตำแหน่งของคุณ (ใช้ได้ภายใน 10 นาที และถูกลบเมื่อใช้แล้ว หรือไม่เกิน 48 ชั่วโมงถ้าไม่ได้ใช้)

เราไม่บันทึกข้อความแชตของคุณ บอตอ่านคำสั่งหรือชื่อสถานที่ที่คุณพิมพ์ (เช่น "สถานะ" "บางบัวทอง") เพื่อตอบกลับแล้วทิ้งไป เก็บเฉพาะค่าที่ระบุข้างบน

ใช้ทำอะไร

เพื่อหาสถานีวัดน้ำที่ใกล้ตำแหน่งของคุณและส่งข้อความแจ้งเตือน (สถานะเปลี่ยน เตือนล่วงหน้า รายงานน้ำท่วมใกล้บ้านที่มีคนยืนยัน และสรุปเช้า 07:00) ตอบคำสั่งของคุณ และแสดงศูนย์พักพิงใกล้เคียง ไม่ใช้เพื่อวัตถุประสงค์อื่น

เก็บนานแค่ไหน และลบอย่างไร

  • เก็บจนกว่าคุณจะสั่งลบ พิมพ์ ยกเลิก ลบทุกอย่างของคุณทันที (ทุกจุดและการตั้งค่า)
  • พิมพ์ ลบจุดที่ 2 หรือเลือกจาก "ตำแหน่งของฉัน" เพื่อลบรายจุด
  • บล็อกบอตหรือเลิกเป็นเพื่อน ระบบลบข้อมูลของคุณให้อัตโนมัติ ถ้าบอตถูกนำออกจากกลุ่ม ข้อมูลของกลุ่มก็ถูกลบ

ผู้ให้บริการ LINE

ข้อความที่คุณส่งและรับกับบอตผ่านระบบของ LINE ซึ่ง LINE ประมวลผลตามนโยบายความเป็นส่วนตัวของ LINE เอง

4. เก็บที่ไหน และใครเข้าถึงได้

  • ข้อมูลของบอตและรายงานน้ำท่วมเก็บในฐานข้อมูลที่ให้บริการโดย Neon (PostgreSQL) และเว็บให้บริการโดย Vercel ทั้งสองเป็นผู้ให้บริการประมวลผลแทนเรา และอาจเก็บข้อมูลนอกประเทศไทย
  • ผู้ดูแลระบบเข้าถึงฐานข้อมูลได้เพื่อดูแลบริการ เราไม่เปิดเผยรหัสผู้ใช้ LINE หรือตำแหน่งของใครต่อสาธารณะ และไม่ขายหรือแบ่งปันข้อมูลให้บุคคลที่สาม ยกเว้นผู้ให้บริการที่จำเป็นต่อการทำงานตามที่ระบุในหน้านี้ หรือเมื่อกฎหมายบังคับ
  • ระบบจำกัดจำนวนผู้ใช้บอตและมีการป้องกันการเข้าถึง (ลายเซ็นของ LINE และรหัสลับของงานเบื้องหลัง) แต่ไม่มีระบบใดปลอดภัยสมบูรณ์ เราจึงเก็บให้น้อยที่สุดเท่าที่ทำงานได้

ข้อมูลระดับน้ำ ศูนย์พักพิง และขอบเขตพื้นที่ เป็นข้อมูลสาธารณะของหน่วยงานรัฐ ไม่เกี่ยวกับข้อมูลส่วนบุคคล

5. สิทธิของคุณ

คุณขอลบข้อมูลของคุณได้เองทุกเมื่อตามวิธีในหัวข้อ 3 และคุณมีสิทธิตามกฎหมายคุ้มครองข้อมูลส่วนบุคคล (PDPA) เช่น ขอทราบว่าเราเก็บอะไรของคุณ ขอแก้ไข ขอให้ลบ หรือคัดค้านการใช้ข้อมูล ถ้าต้องการใช้สิทธิที่ทำเองในบอตไม่ได้ ให้ติดต่อผู้ดูแลผ่านช่องทางติดต่อที่ระบุในโปรไฟล์ของบัญชี LINE Official Account "น้ำใกล้บ้านฉัน" โดยระบุสิ่งที่ต้องการ เราอาจขอให้พิสูจน์ว่าบัญชี LINE นั้นเป็นของคุณ

การให้ตำแหน่งเป็นความสมัครใจ คุณใช้เว็บและดูข้อมูลระดับน้ำได้โดยไม่ต้องให้ตำแหน่งหรือใช้บอตเลย (เลือกจังหวัด/อำเภอ/ตำบลเองได้) การไม่ให้ตำแหน่งแค่ทำให้บอตส่งการแจ้งเตือนเฉพาะจุดไม่ได้

6. เด็ก และการเปลี่ยนแปลงนโยบาย

บริการนี้ไม่ได้ออกแบบสำหรับเก็บข้อมูลของเด็กโดยเฉพาะ ถ้าผู้ปกครองพบว่าบุตรหลานส่งตำแหน่งให้บอต ให้พิมพ์ "ยกเลิก" ในบัญชีของเด็ก หรือติดต่อผู้ดูแลตามหัวข้อ 5 เราจะแจ้งการเปลี่ยนแปลงสำคัญของนโยบายด้วยการปรับวันที่ด้านบนของหน้านี้ ถ้ามีการเปลี่ยนวิธีเก็บข้อมูลในทางที่มีผลกับคุณมากขึ้น เราจะแจ้งผ่านบอตด้วย

บริการนี้ให้ข้อมูลประกอบการตัดสินใจเท่านั้น ไม่ใช่ประกาศทางการ ดูรายละเอียดวิธีใช้ที่ คู่มือการใช้งาน
